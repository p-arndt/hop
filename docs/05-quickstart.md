```bash
hop            # launch the TUI
```

On a first run with no hosts, hop offers to import `~/.ssh/config` for you: one [[enter]] and
your list is full. Then, in the TUI: [[↑]]/[[↓]] to move, [[enter]] to connect, [[ctrl+o]]
[[o]] to come back out. That is the whole model.
